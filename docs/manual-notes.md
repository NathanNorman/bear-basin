# Bear Basin manual notes (step-by-step reading)
## Hardware (p9): Bolt M821 x2, M833 x16, M865 x8, M896 x28, M8107 x48; Nut BM818 x21, BM825 x14, T-nut NM815 x80; Washer x8;
Screw M6SW35 x20, M6SW55 x12, M8SW50 x70, M8SW60 x2, SW16 x24, SW35 x405, SW50 x54, SW60 x124, SW75 x20; self-locking nut x4.
(naming guess: M8107 = M8 bolt 107mm; SW60 = 60mm wood screw; M6SW35 = 6mm structural screw 35mm)
## Tower frame (steps 7-30)
- Two side frames, each = 3 Tower Legs on a Base Board, + Floor Rail at deck height:
  - Frame A: C01, C04, C02 + Base Board S04A (6x M896 bolts into T-nuts NM815) + Floor Rail K07 (5x M8107). Extra holes between C04 and C02.
  - Frame B: C01, C04, C03 + Base Board S04 (6x M896) + Floor Rail K06 (5x M8107; sloped edge up).
  - Leg bottoms angled (legs lean). Frame is a trapezoid: wider at the base.
- Frames stood up facing each other (step 27-28), joined by Floor Rails K08 (C02-C01 and C03-C01, 2x M8107 each) at deck height.
## Swing (steps 147-163)
- A-frame = 2 Beam Support Braces C20 in Y-Bracket DRB-01 (+ Leg Bracket, 2x M6SW35 each), End Support F08 across (4x SW60) -- parts list calls it F30?
- Swing Beam B03 into I-Bracket DRB-02 (2x M6SW35); I-bracket screwed to Tower Leg C05 (2+2 M6SW35) at deck-wall-top height.
- Y-bracket to beam 2x M6SW35. 4 swing hangers through beam w/ washer + self-locking nut. Swings on ROPES, seat 14in above ground.
## Tower (steps 31-48)
- Front/back base boards S03 (x2): S03 joins C03-C01 (4x M896), S03 joins C02-C01 (4x M896). So base = rectangle: S04/S04A sides (3 legs each), S03 ends.
- Mid legs C06 and C05 on the S03 faces: each to K08 (1x M8107 + T-nut) and to S03 (2x M896 + 2 T-nuts). 8 tower legs total, ALL lean inward (trapezoid every face).
- Floor Support blocks FA17 (8): under floor rails at legs C03, C01, C02, C01, C01(facing C02), C06(facing C01)... 2x SW50 each.
- Knee braces KA13 (8): 2 per corner leg (C01 x2, C02, C03), each 1x M865 bolt into floor rail + 1x M8SW50 into leg; top flush with floor rail.
- Floor Support KA11 joist(s) between C05 and C06 (4x SW75 per). Wood Braces C11 (4) = blocks on K08, 2x M8107 + T-nuts each (2 per K08).
## Roof assembly (steps ~120-139): separate unit lifted on top.
- Ring of Connect Boards F11 (4), F12 (2), F13 (2) with angled ends; bolted to matching connect boards on main structure with M833 + BM825 nuts (F12: 4, F11: 4+4, F13: 2).
- Flared posts Tower Leg C09 (4, corners) + C10 (4); roof rails F14 (3), F15 (1), F16 (4) at eave; 4 rafters KA12 to a hip apex w/ Roof Brace KA09 (2x SW60 each). RECTANGULAR plan (tarp rectangular). Tarp 24x SW16.
## Picnic table on deck (steps 140-145): Table legs CA10 (4), Bench supports F03 (2, 4x M8SW50 each), Table supports F01 (2, 4x SW60 each), Bench tops F08+F02 (8x SW50 per bench), Table top W05 x4 (8x SW35 per pair), table support ~25.5in long (centre 12.75in).
